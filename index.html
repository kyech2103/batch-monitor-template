실시간 공정 모니터링 및 각 구역별 연동 기능 안내
처음이라면: 오른쪽 위 [작업자] 배지에서 로그인한 뒤 사용하세요. 로그인해야 본인 할 일이 보이고, 저장·이동 기록에 이름이 남습니다.

👤 로그인

  • 로그인: 오른쪽 위 [작업자] 배지를 눌러 관리자가 등록한 이메일과 비밀번호를 입력합니다.
  • 로그아웃: 배지를 다시 눌러 로그아웃합니다.
  • 기록: 로그인 후 하는 저장·이동은 작업자 이름과 함께 기록되고, 화면에 작업자 이름이 옅게 표시됩니다.

📍 평면도와 배치 조작

  • 요약 띠: 진행 중 · 48시간 내 종료 · 대기 · 보관 중 · 내 오늘 할 일 수를 한눈에 봅니다.
  • 배치 아이콘: 한 번 누르면 오른쪽 [선택한 배치]에 상세가, 두 번 누르면 일정 편집 창이 열립니다.
  • 구역 이동: 아이콘을 끌어 다른 공정실로 옮깁니다. 진행 구역은 아이콘 아래 얇은 막대로 진행률을 보여 줍니다.
  • 로트 검색: 위쪽 검색칸(Ctrl+K)에 로트 번호를 넣으면 해당 배치를 찾아 줍니다.

📋 배치 생성과 일정

  • 배치 생성: 위쪽 [배치 생성]에서 로트와 공정1~공정5 공정 일정을 입력하면 단계별 시각이 자동 계산됩니다.
  • 템플릿: 자주 쓰는 일정은 [템플릿 저장]·[템플릿 불러오기]로 재사용합니다.
  • 타임라인: [타임라인] 탭에서 배치별 공정 일정을 시간 막대로 봅니다.
  • 다가오는 일정: 오른쪽 패널에 72시간 안에 예정된 공정이 표시됩니다.

🏢 기타 구역 · 창고 · 장비

  • 기타 구역: 오른쪽 [부품 보관실]·[포장실 비품실]·[비품실]·[자재 창고]에서 선반 적재·보관 위치를 관리합니다.
  • 완제품 창고: 포장이 끝난 배치가 보관됩니다. 잘못 넣었으면 [꺼내오기]로 평면도에 되돌립니다.
  • 장비: 오른쪽 장비 카드에서 가동 예약을 등록·수정합니다. 다른 예약과 시간이 겹치면 저장되지 않습니다. 품목·소요 시간·시작/종료 알림 받을 사람은 [템플릿 관리] 탭에서 정합니다(PC).

👥 공정 담당자

  • 담당자 편성: 위쪽 [공정 담당자]에서 공정별 당일 담당자를 적고 [저장]하면 평면도에 바로 반영됩니다.
  • 여러 명: 한 칸에 여러 명은 쉼표로 적습니다 (예: 홍길동, 김철수). 적힌 사람 모두 그 칸의 할 일과 알림을 받습니다.

🗓️ 일일 투두

  • 보는 범위: 사원·주임은 본인 할 일만, 대리 이상과 관리자는 전체 할 일과 담당자 필터를 봅니다.
  • 근무시간: 평일 09:00~18:00 안에서만 배정되고, 주말·공휴일에는 할 일이 없습니다.
  • 일정 반영: 배치를 새로 등록하거나 일정을 바꿨으면 [일정 반영]을 눌러 할 일을 다시 만듭니다.
  • 규칙 관리: 대리 이상은 [⚙️ 규칙 관리]에서 할 일이 생기는 규칙을 고칠 수 있습니다.

📱 휴대폰과 작업 알림

  • 휴대폰으로 열기: 같은 주소를 휴대폰에서 열면 배치 · 할 일 · 장비 · 더보기 탭으로 된 모바일 화면이 나옵니다.
  • 작업 알림: PC는 위쪽 🔔, 휴대폰은 [더보기 → 작업 알림 설정]에서 켜면 할 일 5분 전에 알림이 옵니다.
  • 아이폰: 홈 화면에 추가한 뒤 그 아이콘으로 열어야 알림을 켤 수 있습니다.

🛠 직원 관리 (관리자만)

  • 직원 관리: 관리자에게만 보이는 위쪽 [직원 관리]에서 직원 등록과 삭제를 합니다. 관리자 지정·해제는 1차 관리자만 할 수 있습니다.
Esc 키를 누르거나 닫기를 클릭하면 창이 닫힙니다.

📱 아이폰은 먼저 앱으로 설치해야 알림을 켤 수 있어요
  1. 사파리로 이 화면을 엽니다. (카톡·네이버·크롬 안에서 열었다면 사파리로 다시 열기)
  2. 주소창 옆 ⋯(점 3개) → 공유를 누릅니다. 화면 아래에 공유 버튼(□↑)이 바로 보이면 그걸 눌러도 됩니다.
  3. 메뉴 목록을 아래로 내려 홈 화면에 추가를 누릅니다. 안 보이면 목록 맨 아래 동작 편집에서 추가합니다.
  4. 웹 앱으로 열기가 켜져 있으면 그대로 두고, 오른쪽 위 추가를 누릅니다.
  5. 사파리는 닫고, 홈 화면에 생긴 공정모니터링 아이콘으로 엽니다.
  6. 아래 더보기 탭 → 작업자 인증을 먼저 하고 → 🔔 작업 알림 설정 → 알림 켜기 → 뜨는 창에서 허용.
  7. 테스트 알림 보내기를 눌러 알림이 오면 끝.
• 한 번 켜 두면 이 기기로 알림이 옵니다. 폰·브라우저를 바꾸면 다시 켜 주세요.
• 브라우저 기록을 지울 때 쿠키 및 사이트 데이터까지 지우면 알림이 꺼집니다. 다시 인증하면 자동으로 켜지고, 안 켜지면 여기서 다시 켜 주세요.
• 화면이 꺼져 있을 때 알림이 늦지 않게: 설정 → 애플리케이션 → Chrome(삼성 인터넷으로 설치했다면 삼성 인터넷) → 배터리 → 제한 없음. 설정 → 배터리 → 백그라운드 사용 제한 → 절전 앱 목록에 있으면 빼기.
• 화면이 꺼져 있어도 제때 울리게 (아이폰, 처음 한 번)
  1. 아이폰 설정 앱 → 알림 → 알림 스타일 아래 목록에서 공정모니터링을 누릅니다.
  2. 알림 허용을 켭니다. (목록에 없거나 켜지지 않으면 앱 아이콘을 지우고 다시 설치한 뒤 알림 켜기 → 허용)
  3. 알림 아래 세 가지(잠금 화면 · 알림 센터 · 배너)를 모두 눌러 체크합니다. 잠금 화면이 빠지면 화면이 꺼져 있을 때 안 보입니다. 아래 배너 스타일은 지속적으로 두면 폰을 쓰는 중에 뜬 알림이 직접 닫을 때까지 남아 있어 놓치지 않습니다.
  4. 사운드를 켜 둡니다. 알림 진동은 사운드와 짝으로 울려서, 사운드를 끄면 진동도 안 옵니다. 진동만 원하면 사운드는 켜 두고 폰을 무음 모드로 쓰세요.
  5. 알림 전달 항목이 보이면 즉시 전달을 고릅니다. ('시간 지정 요약'을 쓰는 폰에만 보이며, 요약에 넣으면 정해진 시각에 몰아서 옵니다)
  6. 집중 모드(방해금지 모드·수면·업무 등)를 쓰면 그동안 알림이 막힙니다. 설정 → 집중 모드 → 쓰는 모드 → 앱 → 다음 알림 허용 → + → 공정모니터링. 쓰는 모드마다 해 줍니다.
  7. 설정을 마치면 앱에서 테스트 알림 보내기 → 바로 화면을 끄고 잠금 화면에 알림이 뜨는지 확인합니다.
